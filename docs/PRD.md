# PRD

EchoNote 첫 버전의 제품 요구 문서입니다. 동작 세부는 [SPEC.md](./SPEC.md)에 적습니다.

## 문제

상용 회의 전사 서비스는 대부분 유료이거나 무료 사용량에 제한이 있습니다. 회의 음성은 사람 목소리가 그대로 담긴 민감한 개인 데이터입니다.

그래서 녹음을 외부 클라우드에 두지 않는 구조가 필요합니다.

## 대상 사용자

- 운영자가 계정을 발급합니다.
- 사용자는 운영자의 Tailscale(기기끼리만 통하는 개인 네트워크)에 들어온 iPhone·Android 사용자입니다.
- 전사는 운영자의 NVIDIA GPU Windows PC(이하 「전사 PC」) 1대를 여러 사용자가 함께 씁니다.
- 앱에는 회원가입 화면이 없고 로그인 화면에 이용 문의 안내만 있습니다.

## 목표

- 녹음·재생·목록·삭제는 전사 PC가 꺼져 있어도 동작합니다.
- 녹음 파일을 Vercel(서버 코드를 올려 실행하는 호스팅)이나 Supabase(데이터베이스·로그인 서비스)에 저장하지 않습니다.
- 카드 등록 없는 무료 도구(Vercel Hobby, Supabase Free, Tailscale 무료)만으로 운영합니다.
- iOS와 Android를 한 코드베이스(Expo React Native)로 만듭니다.
- 서버에 저장하는 전사문은 암호문으로만 둡니다.

## 첫 버전 범위 밖

### 하지 않기로 한 것

- 스토어 배포나 외부인 체험 경로가 없습니다.
- 업로드·전사는 개인 Tailscale 네트워크 전용입니다.

### 다음 버전 후보

- 오전사(잘못 전사된 부분) 후보 탐지
- 요약
- 화자 구분
- Electron macOS 앱
- 계정 기반 복원
- 개인정보 처리방침
- 서버 자동 삭제
- 전사문 열쇠용 열쇠(KEK) 회전 절차

## 기능 요구사항

대괄호(`[ ]`)는 화면의 버튼 표기입니다.

### F1 녹음

- 앱을 나가거나 화면을 꺼도 iOS·Android 백그라운드 녹음이 계속됩니다.
- 일시정지·재개·종료가 가능합니다.
- 녹음 중 취소하면 「녹음을 버릴까요?」 확인 후 삭제합니다.
- 제목을 입력하지 않으면 기본 이름이 붙습니다.

### F2 파일 업로드

- 기기의 m4a 파일을 가져와 회의로 등록합니다.
- 512 MiB(화면 표기 512MB) 초과, m4a 아님, 길이를 읽을 수 없는 파일은 거부하고 이유를 안내합니다.
- 확장자를 뺀 원본 파일 이름을 회의 제목으로 씁니다.

### F3 목록

- 등록 시각 최신순으로 20개씩 이어 불러옵니다.
- 연도로 필터링합니다.
- 여러 개를 선택해 일괄 삭제할 수 있습니다(「삭제하시겠습니까? 복구가 불가능합니다.」 확인).
- 전사를 요청한 회의는 상태 칩(요청 미완료/대기/변환 중/완료/실패)을 보입니다.
- 전사를 요청하지 않은 회의는 칩 대신 화살표를 보입니다.
- 이때 메타 문구는 「녹음만 저장됨」이며 길이를 모르면 「녹음 대기」입니다.

### F4 회의 상세

- 재생 중 10초 앞·뒤로 이동할 수 있습니다.
- 제목을 1~80자로 수정할 수 있습니다.

### F5 전사 요청

- [텍스트로 변환]으로 요청합니다.
- 녹음 저장 직후 상세 화면은 한 번 자동으로 요청합니다.
- 진행 상태(준비 중·요청 중(진행률 %)·대기 중·변환 중)가 표시됩니다.
- 실패하면 이유를 보여주고 [다시 시도]로 새로 요청할 수 있습니다.
- 상태 칩 이름(F3)과 이 진행 상태 이름(F5)은 화면마다 다른 표기입니다.

### F6 전사 PC 꺼짐 안내

- 업로드 전에 전사 PC 준비 상태를 확인합니다.
- 업로드 수신기의 `GET /live`가 5초 안에 204(정상 응답)를 돌려주지 않으면 전사 PC가 꺼진 것으로 판정합니다.
- 이때 「데스크탑에 연결할 수 없습니다」와 전사 PC 전원·이 기기 Tailscale 연결 확인 안내를 보여줍니다.
- [다시 확인]으로 새 job 없이 같은 요청을 이어 갑니다.
- 앱이 전사 PC를 원격으로 켜지 않습니다.

### F7 전사 결과

- 문장 단위 목록으로 보여줍니다.
- 문장을 누르면 그 문장이 시작하는 위치부터 재생됩니다.

### F8 내보내기

- 회의 상세에서 전사 텍스트(.txt)나 녹음(.m4a)을 골라 OS 저장 화면에서 고른 위치에 저장합니다.
  - iOS는 문서 선택기, Android는 저장소 접근 프레임워크를 씁니다.
- 전사가 없으면 종류 선택이 잠겨 녹음(.m4a)만 저장합니다.
- 녹음 파일을 가져오는 중이거나 내보내는 중에는 버튼이 비활성입니다.

### F9 로그인·로그아웃

- Supabase Auth(Supabase의 로그인 서비스) 이메일·비밀번호로 로그인합니다.
- 세션은 iOS Keychain·Android Keystore(OS 보안 저장소)에 저장됩니다.
- 세션이 만료되면 「로그인이 만료됐습니다」를 안내합니다.
- 녹음 중이면 녹음은 계속되고 녹음을 마치면 로그인 화면으로 이동합니다.

## 비기능 요구사항

**개인정보**

- 녹음 원본은 기기와 전사 PC에만 남습니다.
- 서버에 저장하는 전사문은 봉투 암호화(envelope encryption, 데이터를 자체 열쇠로 잠그고 그 열쇠를 다시 상위 열쇠로 잠그는 방식)로 보호합니다.
- 로그에 본문과 열쇠를 남기지 않습니다.
- 자세한 위치와 접근 범위는 [README.md의 데이터 위치와 보호](../README.md#데이터-위치와-보호)에 적습니다.

**격리**

- 다른 사용자의 전사 요청(job)은 없는 것과 같게 404로 응답합니다.
- 전사 PC는 사용자별로 공정한 순서로 작업을 가져갑니다([DECISIONS.md 7](./DECISIONS.md#7-사용자별로-공정하게-작업을-가져가는-순서를-만든다)).

**용량**

- 전사 결과 길이 6시간 상한입니다.
- 세부는 [SPEC.md의 한도와 수치](./SPEC.md#한도와-수치)에 적습니다.

**신뢰성**

- Worker(전사 작업을 실행하는 상시 프로세스)가 처리 중 멈춰도 job은 다른 claim이 다시 가져가 처리하고 정해진 횟수를 넘으면 실패로 끝나야 합니다.
- 자세한 동작은 [ARCHITECTURE.md의 실패할 때](./ARCHITECTURE.md#실패할-때)에 적습니다.

**플랫폼**

- 같은 코드, 같은 앱 버전을 iPhone과 Android 실기기에서 검증해야 합니다.
